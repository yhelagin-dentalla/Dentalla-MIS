## Что уже кодируется
Первым production UI выбран единый `Patient Workspace` — полная карточка пациента, общая для ролей. Информация не сваливается на один экран: используется постоянный header + основные вкладки.

Вкладки первой реализации:
1. Обзор
2. План лечения
3. История болезни
4. Изображения
5. Коммуникации
6. Приёмы
7. Финансы
8. Документы

## Редактирование
- ФИО, телефон, email, адрес, паспорт, место работы, профессия, источник — через SideSheet «Редактирование пациента».
- Клинические данные в будущем редактируются только в соответствующем Encounter/clinical workflow и по EffectivePermission.
- Финансовые факты не редактируются как обычные поля: изменения через операции/коррекции.
